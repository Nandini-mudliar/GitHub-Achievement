## <a id="profile-visibility"></a>👁️ Profile Visibility

Achievement visibility is controlled by GitHub and may depend on account settings and eligibility.

- **Profile settings:** Review your [GitHub profile settings](https://github.com/settings).
- **Appearance settings:** Change your [preferred emoji skin tone](https://github.com/settings/appearance).
- **Achievement documentation:** Read GitHub's [official guide to profile badges](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/personalizing-your-profile#displaying-badges-on-your-profile).
